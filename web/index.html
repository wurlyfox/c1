c1 web

Unofficial browser build of the c1 engine. No game data is included: you need the level files from your own Crash Bandicoot (NTSC-U, SCUS-94900) disc.

Loading…

Files are read locally and kept in this browser's storage. Nothing is uploaded.

Keyboard

Click a key to change it, then press the new one (Esc cancels). Gamepads work too. On phones and tablets an on-screen controller appears; you can move, resize or hide its buttons from the ☰ menu.

Debug

Live engine state and a log of what the game and the page do. Toggle it while playing with F2 or from the ☰ menu.

Saves one of the stored level files to your computer, for example to reproduce a problem in a single level.

Drag a control to move it. Tap one to select it, then resize or hide it.
