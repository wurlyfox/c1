Download the game

The quickest way: the game is downloaded in small parts and kept in this browser. If the connection drops, it carries on where it stopped.

1

Use your disc image

Choose the .bin (or .iso) of your Crash Bandicoot disc, NTSC-U version (SCUS-94900). Only what the game needs is copied.

2

Use a game ZIP

A smaller file with just the levels, handy for phones. Make it once on a computer with the converter.

Everything stays on this device. Nothing is uploaded.

Saved games

The game saves to a memory card kept in this browser (15 slots). Choose Load Game on the title screen to continue.

Controls

Click a key to change it, then press the new one (Esc cancels). Gamepads work too. On phones and tablets an on-screen controller appears; you can move, resize or hide its buttons from the ☰ menu while playing.

Advanced

Game files

Saves one of the stored level files to your computer, for example to reproduce a problem in a single level.

Drag a control to move it. Tap one to select it, then resize or hide it.
