Download the game

The quickest way: the game is downloaded in small parts and kept in this browser. If the connection drops, it carries on where it stopped.

1

Use your disc image

Choose the .bin (or .iso) of your Crash Bandicoot disc, NTSC-U version (SCUS-94900). Only what the game needs is copied.

2

Use a game ZIP

A smaller file with just the levels, handy for phones. Make it once on a computer with the converter.

Everything stays on this device. Nothing is uploaded.

Saved games

The game saves to a memory card kept in this browser (15 slots). Choose Load Game on the title screen to continue.

Controls

Click a key to change it, then press the new one (Esc cancels). Gamepads work too. On phones and tablets an on-screen controller appears; you can move, resize or hide its buttons from the ☰ menu while playing.

Advanced

Game files

Saves one of the stored level files to your computer, for example to reproduce a problem in a single level.

Install it as an app

Add the game to your home screen: it opens full screen, without the browser bars, and keeps working without a connection once it is installed.

iPhone and iPad

  1. Open this page in Safari.
  2. Tap Share (the square with an arrow).
  3. Choose Add to Home Screen, then Add.
  4. Open the game from its icon. Safari deletes the data of web pages that are not visited for 7 days, but not that of apps on the home screen.

Android

  1. Open this page in Chrome.
  2. Tap the menu ⋮ at the top right.
  3. Choose Install app (or Add to Home screen), then Install.
  4. Open the game from its icon.

This page is opened over plain http from another device, so the browser can only add a shortcut: it will need this computer to be running. For the full app, open it on the computer itself (localhost) or serve it over https.
